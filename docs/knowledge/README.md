## Evidence vocabulary
- **Source inspected:** a tracked implementation or configuration exists. This does not prove runtime behavior.
- **Recorded test:** a repository report describes execution. This import did not rerun the ISO or independently validate its checksum.
- **Recorded owner decision:** a repository decision attributes acceptance to the owner. This is distinct from personally observing the original approval.
- **Design / plan:** requested behavior, not working software.
- **Conversation claim:** speaker-attributed historical statement; it may be corrected by later evidence.
- **Unavailable:** source or asset was not returned or is absent from the inspected tree.

Visual approval is not software approval. A single successful boot is not full component acceptance. Future updates should cite a message ID, decision, test report, or commit and retain superseded claims as history.
