# AALLDM — large edition
Official expansion: **A All Large Linux Distribution Model** (D-0002). Intended for newer PCs. Base system, minimum hardware and CPU architectures remain undecided in the inspected status record.

## Visual baseline
[D-0003](../../ai-bridge/decisions/D-0003-aalldm-visual-design-approved.md) records owner acceptance on **2026-10-18** of final **Almond Fusion**, based on **Design 03 — Almond Custom**:
- Graphite/charcoal with restrained gold and silver accents.
- Right-side translucent Almond Glass application bar.
- Optional widgets and Almond Spaces.
- Distinct modern wallpaper and unaltered official logo.

Earlier images reportedly resembled AALDM too closely. “Fusion V2” occurs in the historical ongoing-design discussion, but absent images prevent identifying which exact exported file is final. No final image was inspected or recreated.

## Status and open design
**DESIGNED, visual baseline approved in the repository decision; no AALLDM software exists at the inspected baseline.** Approval of appearance does not approve an implementation specification.

Glass styles and layout controls, Spaces restoration/multi-monitor behavior, “Almond Files Pro — Adaptive Minimalist,” and “Unified Frame” are directions with incomplete specifications. Chrome is recorded as preferred browser in PROJECT_STATUS; redistribution is unresolved and it is not an installed/default-browser claim.

Medium/High effects belong to the AALLDM direction under current rules. Broader performance-mode scope still needs the T-0002 decision. There are no measured mode budgets, supported-hardware claims, or acceptance tests.

Next evidence needed: final original mockups and message associations, explicit component behavior, edition/version scope and an approved implementation task. See [assets](ASSETS.md), [components](COMPONENTS.md), and [chronology](DECISIONS.md).
