# Reports

Written by the bridge, one file per step, never edited afterwards except to fill in the implementer's text sections:

- `T-0001-impl-1.md` — implementation report (written by `bridge finish`, completed by the implementer)
- `T-0001-review-1.md` + `.json` — review (from `bridge in`, `bridge review` or the GitHub Action)

The Git history and pull requests are the source of truth for code; these files explain it.
