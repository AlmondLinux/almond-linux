# T-0007 — implementation report 1

**Task:** Install Almond Linux option with Calamares

## What changed and why

Adds an "Install Almond Linux" option to the live system using Debian 13's Calamares (3.3.14) and Debian's helper modules (calamares-settings-debian 13.0.13). Almond's settings and branding replace Debian's. Full write-up, file list, risks and test plan: [docs/INSTALLER.md](../../docs/INSTALLER.md).

- **Packages (sensitive):** `calamares` and `calamares-settings-debian` added to `aaldm.list.chroot`. New `aaldm-installer.list.binary` puts GRUB (BIOS and UEFI, signed), shim and cryptsetup into a package pool on the ISO for the new system. Every name was checked in Debian 13 with the madison API. The `#if ARCHITECTURE amd64` syntax was checked against live-build 1:20250505's `functions/packagelists.sh`.
- **Hook (sensitive):** new `config/hooks/live/0300-almond-installer.hook.chroot`. It diverts Debian's "Install Debian" entry, its autostart icon and three Calamares config files with local `dpkg-divert`, installs Almond's, and links the branding images to the logo PNGs already in `/usr/share/pixmaps`. It skips itself if Calamares is missing.
- **Almond files** (`desktop/defaults/`, not sensitive): Calamares `settings.conf` (Debian's sequence, branding `almond`, no plymouthcfg, an Almond clean-up step, a confirmation before installing); `packages.conf` (removes live packages and the installer from the new system); `welcome.conf`; `shellprocess-almondcleanup.conf` (removes Almond's installer files and undoes the diversions in the new system); `branding.desc` (light sidebar, so the full-colour logo stays on a light background: contrast 14.1:1 and 12.0:1); the `almond-install` wrapper (pkexec, live session only); the launcher entry; the desktop-icon autostart.

Checked: `sh -n` and `dash -n` for the hook and both scripts; the five YAML files parse (PyYAML); `ai-bridge/bridge check` passes.

Not done: no Almond-specific password rules (Debian's: any non-empty password), no GRUB distributor name, no QML slideshow (a single image is used instead).
