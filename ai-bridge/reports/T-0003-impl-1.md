# T-0003 — implementation report 1

**Task:** Launcher fixes from the first VM test

## What changed and why

Fixes the launcher problems from the 2026-10-17 VM test (RESULTS.md items 2–4).

- **Hibernate pre-selected / selection not following typing.** Cause found in `almond-launch`: rofi ran with `-hover-select`, which makes the tile under the mouse pointer the selected one. The launcher opens centred, under a resting pointer, so a random tile (Hibernate, Brightness) was selected, and after typing the selection stayed on the tile under the pointer. Removed `-hover-select`; clicking still opens the clicked tile (`-me-accept-entry MousePrimary`).
- **Power actions in Apps.** "Hibernate" was not from Almond's System mode: it is LXQt's `lxqt-hibernate.desktop`, listed by rofi's Apps mode with no Almond confirmation. Eight `Hidden=true` overrides in `desktop/defaults/usr/local/share/applications/` hide LXQt's Hibernate, Suspend, Reboot, Shutdown, Log out, Leave and Lock Screen entries, and the Rofi Theme Selector (a developer tool). The build already copies `desktop/defaults/usr/` to `/usr/`. Checked in rofi 1.7.5's source (`source/modes/drun.c`): a `Hidden=true` entry puts its ID on a disabled list, and later files with the same ID are skipped. Power actions stay in the System mode, which asks before Restart, Shut Down and Log Out.
- **Lock without a screen locker.** `almond-launch-power` shows Lock only when xscreensaver, light-locker, xsecurelock, slock, i3lock or xlock is installed; choosing Lock without one just redraws the menu. Exercised on macOS with `dash`: without a locker the menu is Settings, Log Out, Sleep, Restart, Shut Down; with a fake `xscreensaver` on PATH, Lock appears.
- **Tiles without icons.** Session Settings, Notifications and File Associations use `preferences-system-session-services`, `preferences-desktop-notification` and `preferences-desktop-filetype-association` (names read from LXQt 2.1.1's upstream desktop files), which neither Almond Pure nor Adwaita has. Added three relative symlinks to `preferences-system.svg`. The fourth tile, Rofi Theme Selector, is now hidden.

Not done: long names are still cut off with "…" (needs a theme change and a look at the real screen).
