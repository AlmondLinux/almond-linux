# T-0012 — Almond Duo desktop app

2026-10-18, local macOS validation. Owner requested a visible, Almond-focused app for Claude and Codex.

## What changed and why

A native AppKit/WKWebView app hosts a standard-library Python loopback service. Ask both runs concurrent read-only responses followed by cross-responses; Build together wraps the tested duo orchestrator. Each job has an isolated clone without a remote, a saved message feed, history, stop control and Markdown export. Claude wrote the frontend; Codex implemented the service/native wrapper and tested their integration.

## Limitations

Local build depends on this Mac’s Python and signed-in CLIs; not notarized for distribution. Keep the app open during work. Visible messages arrive at stage completion, not token-by-token. Fresh agents use repository context, not existing chat histories. Follow-up context is bounded to 24,000 characters. Only completed runs inherit their committed workspace; other follow-ups start a new job from the bundled snapshot. No automatic publication. No OS/ISO changes or new boot claims.
